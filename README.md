# INOVATEA — Assistente Conversacional para Crianças com TEA

## Descrição do Projeto

O **INOVATEA** é um sistema web desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas da Faculdade Metropolitana de Manaus (FAMETRO).

O projeto consiste em um assistente conversacional inteligente voltado ao treinamento de habilidades sociais para crianças com Transtorno do Espectro Autista (TEA), utilizando princípios de computação afetiva, design adaptado para neurodiversidade e inteligência artificial conversacional.

A proposta do sistema é fornecer um ambiente digital seguro, previsível e com baixa sobrecarga sensorial, auxiliando no desenvolvimento da comunicação, autonomia e interação social de crianças neurodivergentes.

---

# Objetivo

O INOVATEA foi desenvolvido com o objetivo de criar uma ferramenta tecnológica acessível e adaptada às necessidades de crianças com TEA, permitindo:

* Treinamento de habilidades sociais;
* Redução da ansiedade em interações sociais;
* Desenvolvimento da comunicação;
* Apoio complementar a terapeutas e responsáveis;
* Aplicação de práticas de acessibilidade e inclusão digital.

Além disso, o sistema busca validar um modelo de design adaptado para neurodiversidade que possa futuramente ser utilizado em instituições públicas, escolas e centros especializados.

---

# Fundamentação do Projeto

O desenvolvimento do sistema foi fundamentado em três pilares principais:

## Processamento Sensorial no TEA

O projeto considera as particularidades cognitivas e sensoriais presentes no Transtorno do Espectro Autista, priorizando:

* Previsibilidade visual;
* Redução de estímulos;
* Organização cognitiva;
* Interfaces simplificadas.

---

## Design Adaptado para Neurodiversidade

A interface do INOVATEA foi construída utilizando heurísticas de usabilidade adaptadas para usuários neurodivergentes, incluindo:

* Uso de tons frios e padronizados;
* Iconografia literal;
* Feedback imediato e positivo;
* Estrutura visual em grid;
* Barra de progresso previsível.

---

## Inteligência Artificial Conversacional

O sistema utiliza um assistente virtual denominado **TEABot**, responsável por conduzir interações sociais estruturadas por meio de:

* Conversas guiadas;
* Emojis e comunicação visual;
* Feedback positivo;
* Texto-para-fala (TTS);
* Interações adaptadas ao ritmo da criança.

# Arquitetura do Sistema

O INOVATEA foi estruturado utilizando arquitetura modular baseada em componentes e serviços.

As principais entidades do sistema são:

* Criança
* Assistente Conversacional
* Interação
* Atividade Social
* Emoção
* Feedback

O sistema permite que a criança realize atividades sociais guiadas enquanto o assistente interpreta respostas e fornece reforço positivo em tempo real.
